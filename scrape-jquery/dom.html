Frontend Web Development

Module Description:

This module is designed to equip you with the fundamental skills and knowledge required to craft visually compelling and interactive web experiences. We'll delve into the core technologies underpinning front-end development, including regular expressions, HTML, CSS, and JavaScript. The curriculum will explore both foundational and advanced concepts within each of these domains, with a strong emphasis on creating responsive web pages that seamlessly adapt to various screen sizes and devices. By the end of this module, you'll possess a robust understanding of front-end development principles and be well-prepared for further academic pursuits or a professional career in the field.

Key Topics:

  • Regular Expressions:
    • Harnessing regular expressions to search and manipulate text data within web applications.
    • Crafting regular expressions to effectively identify patterns within textual information.
    • Mastering advanced regular expression techniques, such as look-around assertions and back-references.
    • Utilizing regular expressions to validate user input and ensure data integrity.
  • HTML & CSS Fundamentals and Advancements:
    • Introduction to HTML and its pivotal role in constructing web page structure.
    • Employing fundamental HTML tags to effectively organize web page content.
    • Styling web page elements using CSS to achieve desired visual presentations.
    • Implementing responsive design principles through the use of media queries and the flexbox layout model.
    • Exploring advanced CSS techniques, such as animations and transitions, to enhance user experience.
  • JavaScript Fundamentals and Advancements:
    • Introduction to JavaScript and its crucial role in creating interactive web applications.
    • Mastering JavaScript syntax, data types, and control flow structures.
    • Manipulating the Document Object Model (DOM) using JavaScript to dynamically alter web page content.
    • Implementing event handling mechanisms to create interactive user experiences.
    • Delving into advanced JavaScript concepts, such as closures and prototypes, to enhance code efficiency and maintainability.
  • Web Scraping with jQuery:
    • Introduction to web scraping techniques and their practical applications in data extraction.
    • Leveraging jQuery selectors to efficiently extract data from web pages.
    • Processing and transforming extracted data using JavaScript for further analysis or utilization.
    • Storing extracted data in structured formats, such as JSON or CSV, for convenient data management.

Learning Objectives:

Upon successful completion of this module, you will be able to:

  • Effectively apply regular expressions to search and manipulate textual data within web applications.
  • Design and develop both basic and advanced HTML/CSS web pages that are both responsive and accessible to users.
  • Develop interactive web applications by effectively applying fundamental and advanced JavaScript programming concepts, including DOM manipulation and event handling.
  • Extract data from websites using web scraping techniques, with a focus on utilizing jQuery for efficient data extraction.

Course Policies on Late Submission

As participants in the Frontend Web Development module, it is essential to understand our policies regarding late submissions. We strongly discourage late submissions of assignments. To avoid penalties, please begin working on your assignments well in advance.

Penalty Structure for Late Submissions:

  • First Late Submission: There will be a 10% deduction from the total marks.
  • Second Late Submission: A 20% deduction will be applied.
  • Subsequent late submissions will incur increasing penalties.

Effective time management is crucial in this course to ensure you meet all deadlines. If you anticipate difficulties submitting on time, please reach out for support or advice well before the due date.

Course Policies on cheating and plagiarism

At African Leadership University, we recognize that the rigorous demands of an intellectually challenging environment can sometimes test students' decision-making abilities. In this context, our academic community provides a support system to foster discussions and reflections on these challenges, promoting high standards of academic integrity.

It is our community's collective responsibility to uphold our university's integrity. Here, you will find practical information on policies, protocols, best practices, and explanations of the institutional values underpinning these guidelines.

While African Leadership University does not have a formal honor code, our policies serve as a cornerstone for community expectations concerning personal integrity.

Specific to our Enterprise Web Development module:

  • Cheating and Plagiarism: Students must not cheat or copy code from another individual's repository. Such actions are in direct violation of our academic integrity policies.
  • Consequences of Academic Dishonesty:
    1. First Offense: Any student caught cheating or copying code for the first time will receive a 20% deduction in their score for that particular assignment.
    2. Repeat Offenses: A student will be reported to the Registrar and the Academic Committee if they cheat or plagiarize after the first offense. The student will then face a disciplinary panel and may be severely penalized.

By adhering to these standards, students ensure their academic journey at African Leadership University is honorable and rewarding.
